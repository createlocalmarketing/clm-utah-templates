Frequently asked questions

Are these fishing rules current?

The rules can change. Check current ADF&G regulations and emergency orders before fishing.

Do all anglers need the same license?

No. Requirements vary by age, residency, target fish, and fishery. Confirm with ADF&G.

Can any visitor use the fish processor?

Do not assume so. Ask each provider about outside-customer eligibility, terms, and current capacity.
