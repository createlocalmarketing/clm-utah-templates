# Create Local Marketing WordPress theme

Brand-specific theme identity: `Create Local Marketing` / `create-local-marketing` / `https://www.createlocalmarketing.com/` / `create-local-marketing` text domain. This is the Create Local Marketing business theme, not a generic theme product.

The theme is a child of Hello Elementor. It owns the brand shell, accessibility basics, design tokens, typography, responsive defaults, and persistent light/dark mode. Elementor Pro Theme Builder remains responsible for editable headers, footers, and page layouts. The first-party core plugin owns reusable business logic, content types, directory data, integrations, and other functionality. Avoid adding overlapping Elementor add-on packs to implement site-specific components.

The green and charcoal values are drawn from the approved Create Local logo artwork. Light mode is the default. Visitors may choose dark mode; the choice is stored locally and follows the operating-system preference until they choose a mode.

The fallback header uses the existing Create Local Marketing wordmark in the WordPress media library. It only appears when an Elementor Theme Builder header is not assigned. Theme and plugin metadata identify the actual business/domain; they are not SEO ranking fields. Search performance is built through verified page URLs, original content, entities, media, structured data, internal links, and a crawlable technical setup.
